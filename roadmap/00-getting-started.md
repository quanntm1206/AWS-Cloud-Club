# Bắt đầu roadmap

## Điều kiện đầu vào

- Biết một ngôn ngữ lập trình, biến, hàm, vòng lặp, cấu trúc dữ liệu và Git cơ bản.
- Máy chạy Python 3.11-3.13, tối thiểu 8 GB RAM; CPU là đủ cho đường học cốt lõi.
- Không cần tài khoản AWS, Colab hoặc Kaggle trước tuần 17.

## Quy tắc học

1. Clone repo mẫu của chủ repo bằng `git clone <REPO_URL>` hoặc download source archive một lần.
2. Chạy baseline trước model phức tạp.
3. Split dữ liệu trước mọi bước học từ dữ liệu.
4. Ghi config, seed, metric, runtime và kết quả âm.
5. Không mua Colab/Kaggle hoặc nâng cấp AWS Paid Plan để hoàn thành bài bắt buộc.
6. Chỉ tick AWS lab sau cleanup và residual scan.

## Nhịp một tuần

- 2 giờ lý thuyết; 2 giờ guided practice; 3-4 giờ lab; 1 giờ assessment; 1 giờ learning log.
- Phần `Stretch` không tính vào 8-10 giờ core.

## Kết quả học tập cục bộ

GitHub chỉ dùng để clone/download repo mẫu do chủ repo phát hành. Người học không fork, không commit/push,
không tạo PR và không nộp bài.

Mỗi tuần lưu cục bộ learning log, code/notebook, test hoặc kiểm tra, metric/bảng kết quả và một đoạn
retrospective để tự đánh giá.
