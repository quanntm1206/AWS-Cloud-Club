# Đóng góp

1. Tạo issue mô tả learning objective hoặc lỗi tái hiện được.
2. Giữ thay đổi nhỏ, cập nhật test và nguồn chính thức liên quan.
3. Chạy `pwsh scripts/check.ps1 -Scope all -Profile ci`.
4. Không commit credential, dataset/model lớn hoặc output notebook.
5. Mọi thay đổi AWS phải giữ denylist, dry-run cleanup và residual scan.
